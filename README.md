# DigiStore

Микросервисная платформа для продажи цифровых товаров (ключи, лицензии, файлы).
Основной клиент — Telegram-бот, архитектура заложена под параллельные фронты 
(веб-сайт, в перспективе VK-бот) без изменения бэкенда.

## Стек
- .NET / C# — микросервисы
- Shared/DigiStore.Enums — общие контракты и enum'ы между сервисами
- WebClients — клиентские приложения (Telegram-бот сейчас, веб-сайт и VK-бот в планах)

## Архитектура

Каждый домен вынесен в отдельный микросервис, что позволяет масштабировать 
и деплоить сервисы независимо:

- **CatalogService** — каталог цифровых товаров, категории, карточки товаров, 
  доступность/остатки лицензий
- **CartService** — корзина пользователя, временное хранение выбранных товаров 
  до оформления заказа
- **OrderService** — оформление заказов, статусы (создан / оплачен / выдан / отменён), 
  выдача цифровых ключей/файлов покупателю после оплаты
- **UserService** — регистрация и профили пользователей, привязка к Telegram/VK ID, 
  история покупок
- **WalletService** — баланс пользователя, пополнения, списания, история транзакций 
  (внутренняя валюта или привязка к внешним платёжным системам)

Fronт-агностичная схема: любой клиент (Telegram-бот, веб, VK-бот) общается 
с одним и тем же набором сервисов через единый API-контракт (Shared).

## Ключевой функционал
- Многоканальная продажа цифровых товаров через Telegram-бота
- Расширяемость под веб-фронт и VK-бота без переписывания бэкенда
- Управление балансом и историей транзакций пользователя
- Автоматическая выдача ключей/лицензий после оплаты
